# 实施任务与课程交付

## P0–P5 任务框架

“框架已实现”仅指相应代码已提供，不表示云端或科学结论已经验收。测试和云端实际状态由运行记录补充，算法 TODO 均由用户填写。

| 阶段 | 框架工作 | 用户工作 | 完成证据 |
|---|---|---|---|
| P0：环境、契约与云核验 | UV 依赖/锁文件、Notebook 单配置入口、运行身份、Modal 锁定镜像和 Volume 接口已实现 | 理解研究假设，确定 Notebook 范围；更换资源后按需复核 | 本地 runtime/数据检查已执行；实际 L4 运行返回 PyTorch 2.11.0+cu128 / CUDA 12.8 并下载产物；仅证明连通与环境，不证明训练完成 |
| P1：数据与联邦环境 | Adult 编码/划分、Gymnasium 状态动作、资源计量、基线和共享预热已实现 | 实现 MLP、FedSGD、采样与后端检查点 | 真实模型指标；同种子可复现；同步更新和整轮预算结算正确 |
| P2：攻击与初始风险 | 上传/真值隔离、实际上传池、攻击耗时 benchmark、预算审计、重构指标已实现 | 实现梯度反演；建立有效攻击与风险估计器 | 实测攻击耗时；攻击优于适当先验基线或如实报告失败；初始风险标签；按运行分组的校准结果 |
| P3：DQN 与调度基线 | 冻结风险版本的训练编排、共享预热、检查点和基线评价路径已实现 | 实现 DQN，按需要扩展 PPO；完成参数搜索与留出验证 | 与透明基线比较；共享预热计费；同预算、多种子调度结果与完整恢复 |
| P4：不确定性审计与核心问题检验 | 实际上传池、主动/周期/随机审计、阶段校准与独立评价接口已实现 | 实现不确定性、风险校准和 replay 版本迁移；检验策略诱导偏移及低估 | 等审计调用/耗时比较；低估与校准证据；独立面板覆盖；有效或无效结果均如实报告 |
| P5：课程整理 | 研究协议、来源表与任务映射已提供 | 汇总真实实验、撰写报告、整理 Git 与演示 | 满足课程格式；结论与保存产物逐项对应；明确失败结果与局限 |

优先顺序是先跑通真实联邦更新和有效攻击，再拟合风险，最后实现策略训练和审计校准。不要用未验证的风险代理直接产生“隐私更安全”的研究结论。

## 核心算法待办

- `FederatedBackend`：MLP 初始化、单客户端梯度、聚合更新、测试集评价、模型/优化器/采样状态恢复。
- `GradientAttack`：梯度匹配与表格重构，严格只使用公开攻击输入；返回原字段格式。
- `RiskEstimator`：训练运行分组、特征缩放、回归/不确定性、校准与版本化持久化。
- `Agent` / `train_agent` / `load_agent`：DQN/PPO、探索/推理、更新循环、回放、终止/截断语义、阶段切换和完整断点。
- 实验与报告：参数探索、独立评价、多种子汇总、负面结果分析、真实云成本整理。

框架不提供这些核心的替代实现。遇到 TODO 会失败并保留错误记录；清除报错的方式是实现相应算法，不是返回常量、随机结果或模拟收敛。

## 验收场景

| 场景 | 要验证的事实 |
|---|---|
| Notebook 默认执行 | 只完成本地运行环境检查和数据准备，不隐式训练或提交云 GPU |
| 配置与复现 | 所有全局参数来自唯一配置单元格，快照包含源码/锁文件身份，旧运行不可覆盖 |
| Gymnasium | 观察空间一致、动作映射正确、同种子可复现、时间/样本终止与轮数截断分开 |
| 资源与曝光 | 绝对时槽资源一致；完整轮超预算仍计量；batch 不错误倍增模型字节；重复采样单独统计 |
| 风险与审计 | Bootstrap 显式缺失；先逐客户端截断再聚合；攻击输入无真值；只审计实际上传 |
| 预热与恢复 | 共享预热只执行一次且计费；同阶段恢复不再 reset；新风险版本按协议清 replay |
| 云端持久化 | 实际 GPU 和软件版本可查；成功/失败均保存状态；检查点可作为新运行输入 |
| 科学结论 | 训练和测试审计隔离；记录预算/覆盖；低估、收益或无收益均由真实产物支持 |

当前框架测试使用测试专用后端，不替代真实模型、真实梯度反演或 Modal 集成验收。不要将阶段代码存在等同于阶段完成。
