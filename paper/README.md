# Written Report Materials

[Project home](../README.md) | [Course checklist](../docs/SUBMISSION.md)

- [main.typ](main.typ): English manuscript skeleton, **not a finished report**.
- [course-acm.typ](course-acm.typ): supporting template.
- [refs/refs.bib](refs/refs.bib): shared bibliography.

The report is the place for problem formulation, algorithm justification,
hyperparameter exploration, results, and limitations. Engineering Markdown
documents only installation, operation, files, provenance, and reproduction.

The optional Chinese draft `main.zh.typ` and author working notes are local
materials, not included in Git. Supply them separately if they are part of the
chosen report deliverable. Updating the Chinese draft does not update the English
skeleton automatically.

Deliver a completed report separately and verify the instructor's requirements:
8–20 pages excluding references, 1.5 line spacing, Arial 12, one-inch margins.
Neither the template nor an old layout receipt establishes compliance for a
new report. Keep source attribution and accurately label incomplete experiments.

Existing figures can be supplied from `figure_assets/main/` with their manifest
and source records. These generated files are not in Git. Do not run legacy
`generate_figures.py` as a prerequisite for the current manuscript.
